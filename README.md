# 온니카톡 (OnlyCartalk) — 견적은 오직 카톡으로

장기렌트 · 리스 · 할부 견적을 **카카오톡으로만** 보내는 사이트입니다. 개인 · 개인사업자 · 법인 모두 대상입니다.
정적 웹사이트이며, 자매 사이트 [mytruck.kr](https://mytruck.kr) 과 같은 틀(차량 카드 홈 + 6단계 견적 폼)을 씁니다.

- 도메인: **https://onlycartalk.com**
- 호스팅: **Cloudflare Workers** → [INFRA.md](INFRA.md)

## 견적이 오가는 길

1. 고객이 차량 · 조건을 고르고 **휴대폰 번호**(필수)와 카카오톡 ID · 이메일(선택)을 남긴다
2. 신청 내용이 **Cloudflare 이메일 라우팅**으로 운영자 메일(`jdgp@jdgp.co.kr`)에 들어온다 — 본문에 "카카오톡으로만 회신 (전화 금지)" 가 찍힌다
3. 운영자가 그 번호(또는 카톡 ID)의 카카오톡으로 견적서를 보낸다. 이메일을 남긴 고객에게는 메일로도 함께 보낸다

## 폴더 구조

```
onlycartalk/
├─ site/                    ← 홈페이지 소스 (여기를 수정합니다)
│   ├─ index.html              홈 (차량 카드 · 이용 방법 · 상품 요약)
│   ├─ products.html           상품안내 (장기렌트 / 리스 / 할부 비교 · 계약 조건)
│   ├─ quote.html              카톡 견적 받기 (6단계 폼)
│   ├─ lowcredit.html          저신용자 전용 장기렌트 (추천받기 폼)
│   ├─ lowcredit-data.js       저신용자 전용 가능 차종 예시 (직접 고치는 데이터 파일)
│   ├─ 404.html
│   ├─ car-data.js             차량 데이터 (자동 생성 — 직접 고치지 말 것)
│   └─ assets/
│       ├─ style.css           공통 디자인
│       ├─ quote.css           견적 폼 디자인
│       ├─ site.js             공통 스크립트 · 카카오톡 채널 주소
│       └─ catalog.js          차량 카드 분류 · 사진 지정
├─ src/index.js              견적 접수 API (`POST /api/quote` → 메일 발송)
├─ tools/acerent-to-car-data.js  에이스렌트 견적기 가격표 → car-data.js 변환기
├─ wrangler.jsonc            Cloudflare Workers 배포 설정 (site 폴더 배포)
├─ INFRA.md
└─ README.md
```

## 견적 폼 6단계

1. **상품구분** — 일반 캐피탈사 상품(1~6등급 이내) / 저신용자 상품(면허증만 있으면 가능, 연체 · 신불자 · 개인회생 무관). mytruck 견적 폼 1단계와 같은 화면이며, 화물차용인 구조변경 · 용도변경 상품은 뺐습니다.
   - 고른 값은 견적 메일의 **상품구분** 줄에 찍힙니다. 이후 단계는 어느 것을 골라도 같습니다.
   - `quote.html?pc=general | low` 로 들어오면 미리 골라져 있습니다.
2. **내차만들기** — 맨 위에서 선택 방식을 고릅니다: **제조사 선택** / **가격대로 선택** (mytruck 「가격으로 제안받기」 와 같은 방식)
   - 가격대로 선택: 희망 월 납입금(40만원 이하 / 50만원 이하 / 70만원 이하 / 70만원 초과) → 차량 종류(승용 / SUV · RV / 그 이외 직접 입력). 차종은 고르지 않고, 메일에 `[가격 제안] 월 ○○ · 차량 종류` 로 들어옵니다.
   - mytruck 과 달리 가격대로 선택해도 **3단계(추가옵션)를 건너뛰지 않습니다.** 상품구분과 관계없이 누구나 고를 수 있습니다.
   - 제조사 선택: 제조사 → 차종 구분 → 모델 → 세부사양 → 트림 → 제조사 옵션 → 색상(선택)
   - 트림가 + 옵션가 + 색상 추가금이 실시간 합산되어 **예상 차량가**로 표시됩니다.
   - 가격표에 없는 차(수입차 등)는 제조사에서 **직접 입력**을 골라 차종을 적습니다.
3. **추가옵션** — 썬팅 / 블랙박스 / 하이패스 / 코일매트 / 유리막 코팅 + 직접 입력
4. **고객정보** — 고객 구분(개인 · 개인사업자 · 법인), 상품 종류(장기렌트 · 리스 · 할부 · 추천받기)
5. **계약조건** — 선납금, 보증금, 계약기간, 연간 주행거리, 정비 서비스 (모두 「미정」 선택 가능)
6. **카톡받기** — 이름·상호, 휴대폰 번호(필수), 카카오톡 ID(선택), 이메일(선택), 개인정보 동의 + 신청 내용 요약

홈의 차량 카드를 누르면 `quote.html?brand=..&cat=..&model=..` 로 넘어가 2단계(내차만들기)가 미리 채워집니다. 고객은 1단계에서 상품 구분만 고르고 넘어가면 됩니다.

## 저신용자 전용 장기렌트 (`/lowcredit`)

(주)제이디엔드가 운영하고, 제휴 렌트사(에이스렌트카 · 하모니렌트카 · 토마토렌트카 등) 보유 차량으로 진행하는 저신용자 전용 상품 페이지입니다. 사이트 화면에는 제휴사 이름을 적지 않고 「제휴 렌트사」 로 씁니다. 신차 견적과 입구가 따로 있습니다.

- 페이지: `site/lowcredit.html` — 버튼 선택 4개 + 휴대폰 번호 + 전용 동의 문구
- 접수: 신차 견적과 같은 `POST /api/quote`. `kind: "lowcredit"` 로 구분하며 메일 제목이 **`[온니카톡 저신용 전용] …`** 으로 들어옵니다. (EmailJS 예비 경로는 쓰지 않습니다)
- 가능 차종 예시: **`site/lowcredit-data.js` 하나만 고치면 됩니다.** 실제 차종 · 금액을 넣은 뒤 `placeholder: false` 로 바꾸면 「임시 표시」 안내가 사라집니다.
- 전환 구분: 완료 시 `octLowCreditConversion()` 호출 (네이버 전환 유형 `OCT_LOWCREDIT_CNV_TYPE`, `dataLayer` 이벤트 `lowcredit_submit`), 완료 화면 주소는 `/lowcredit#done`
- 표현 규칙: 「무심사」 「무조건 승인」 「100% 가능」 「자체 심사」 는 쓰지 않고 「면허증만 있으면 가능」 「연체 / 개인회생 / 신불자 신청 가능」 「당일 회신」 을 씁니다. 플릿케어 링크는 넣지 않습니다.

## 자주 하는 작업

> 홈 카톡 예시의 「월 ○○만원」 은 일부러 금액을 넣지 않습니다. 샘플 견적은 고객이 요청하면 운영자가 카톡 · 이메일로 따로 보냅니다.

### 카카오톡 채널 연결하기

채널을 만든 뒤 `site/assets/site.js` 맨 위의 한 줄에 주소를 넣습니다.

```js
var OCT_KAKAO_CHANNEL = "https://pf.kakao.com/_abcdE";
```

비워 두면 「카톡 채널로 문의」 「카톡 문의」 「카톡 채널 추가하기」 버튼은 화면에 나오지 않습니다.
넣으면 홈 · 모바일 하단 바 · 견적 완료 화면에 한꺼번에 켜집니다.

### 가격표(차량 데이터) 갱신하기

차량가 · 제조사 옵션 · 색상은 **에이스렌트 견적기 가격표를 그대로 씁니다** (견적기에 있는 차량 전부).
원본은 acerent 저장소의 `src/data/quote-data.json` 입니다.

1. acerent 저장소를 onlycartalk 옆 폴더에 받아 두고 최신으로 맞춥니다 (`git pull`)
2. `node tools/acerent-to-car-data.js` 를 실행하면 `site/car-data.js` 가 새로 만들어집니다
   (경로가 다르면 `node tools/acerent-to-car-data.js "<quote-data.json 경로>"`)
3. 커밋 후 `main` 브랜치에 push 하면 자동 배포됩니다

- 색상표가 없는 특장차는 같은 차의 카고 색상을 씁니다. 포터II Electric 은 색상표가 없어 색상 칸이 보이지 않습니다.
- 원본의 `Hybird` 같은 오타는 화면에 보일 때 `Hybrid` 로 바로잡습니다 (`catalog.js` 의 `fixName`).
- 차종이 추가되면 홈 카드에 자동으로 나타납니다. 탭 분류가 어색하면 `catalog.js` 의 규칙을 고칩니다.

### 차량 사진 넣기

사진이 없는 차는 실루엣 그림이 나옵니다. 사진을 `site/assets/cars/` 에 넣고
`site/assets/catalog.js` 의 `CAR_PHOTOS` 에 아래처럼 적으면 그 차부터 바뀝니다.

```js
const CAR_PHOTOS = {
  "그랜저": "assets/cars/grandeur.png",
};
```

### 수정하고 배포하기

`site/` 안의 파일을 고치고 `main` 브랜치에 push 하면 Cloudflare가 자동 배포합니다.

```bash
git add .
git commit -m "..."
git push
```

## 견적 메일

견적 폼은 `POST /api/quote` 로 보내고, Worker(`src/index.js`)가 Cloudflare 이메일 라우팅으로 메일을 보냅니다.

| 항목 | 값 | 바꾸는 곳 |
|---|---|---|
| 받는 주소 | `jdgp@jdgp.co.kr` | `wrangler.jsonc` 의 `MAIL_TO` 와 `send_email.destination_address` (둘 다) |
| 보내는 주소 | `noti@onlycartalk.com` | `wrangler.jsonc` 의 `MAIL_FROM` |

- 받는 주소는 Cloudflare 대시보드 → onlycartalk.com → 이메일 → 이메일 라우팅 → **대상 주소**에 인증되어 있어야 합니다. 인증되지 않은 주소로는 발송되지 않습니다.
- 고객이 이메일을 남기면 그 주소가 Reply-To 로 들어가, 메일에서 바로 답장할 수 있습니다.
- 발송 실패는 Worker 로그(관찰 가능성)에 `견적 메일 발송 실패` 로 남습니다.

## EmailJS (예비)

위 접수가 실패했을 때만 EmailJS 로 보냅니다. 신청이 사라지지 않게 하려는 안전장치이며, 이 경로의 메일은 EmailJS 템플릿의 To Email 로 갑니다.

`site/quote.html` 안에 키가 들어 있습니다. 템플릿 본문은 코드(HTML) 모드에서 아래 하나면 됩니다.

```html
<pre style="font-family:'Courier New',monospace;font-size:13px;line-height:1.7;">
{{quote_detail}}
</pre>
```

- 이메일은 선택 항목이라 `{{email}}` 이 빈 값으로 올 수 있습니다. 템플릿의 **Reply To 에 `{{email}}` 이 들어 있으면 지우는 편이 안전**합니다.
- 제목에는 `{{customer_name}}` `{{car_full}}` `{{phone}}` `{{kakao_id}}` 를 쓸 수 있습니다.
- `Account → Security → Allowed Origins` 에 `https://onlycartalk.com` 을 넣어 두세요.

## 광고 링크 · 유입경로 추적

주소 뒤에 `?src=` 를 붙이면 견적 메일의 **유입경로** 항목에 그대로 찍힙니다.

```
https://onlycartalk.com/quote.html?src=insta
https://onlycartalk.com/q?src=naver&utm_campaign=11월
```

`src`, `ref`, `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` 을 인식하고,
홈으로 들어와 견적 버튼을 눌러도 값이 따라갑니다.

### 광고를 켜기 전에 반드시 할 것

**전환추적을 먼저 설치한다.** mytruck 은 이 순서를 지키지 않아
사흘간 클릭 40회에 10만 원을 쓰고도 성과를 측정하지 못했다.

전환 보고는 `wcs.cnv` 로 해야 한다. `wcs.trans` 는 장바구니 · 구매 전환용이라
신청 · 상담 전환을 집계하지 않는다. 전환 보고 함수 `octConversion` 은 이미 `site/assets/site.js` 에
들어 있으므로, 각 페이지 아래쪽 `wcs_add["wa"]` 에 인증키만 넣으면 된다.

설치 후 네이버에서 받은 메일의 **자가설치 후 검수요청**까지 마쳐야 집계가 시작된다.
