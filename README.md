# OnlyCartalk — 법인 · 개인사업자 승용차 리스

정적 웹사이트입니다. 서버 없이 정적 파일만으로 동작하며,
견적 신청은 EmailJS를 통해 이메일로 전달됩니다.

- 도메인: **https://onlycartalk.com**
- 호스팅: **Netlify** → [INFRA.md](INFRA.md)
- 자매 사이트: [mytruck.kr](https://mytruck.kr) (1톤 화물차 리스)

## 폴더 구조

```
onlycartalk/
├─ site/                  ← 홈페이지 소스 (여기를 수정합니다)
│   └─ index.html            견적 신청 (단일 페이지)
├─ netlify.toml            배포 설정 (publish = site)
├─ INFRA.md                도메인 · DNS · 호스팅 설정 기록
└─ README.md
```

## 수정하고 배포하기

`site/` 안의 파일을 고치고 `main` 브랜치에 push 하면 Netlify가 자동 배포합니다.

```bash
git add site/
git commit -m "..."
git push
```

### 광고를 켜기 전에 반드시 할 것

**전환추적을 먼저 설치한다.** mytruck 은 이 순서를 지키지 않아
사흘간 클릭 40회에 10만 원을 쓰고도 성과를 측정하지 못했다.

전환 보고는 `wcs.cnv` 로 해야 한다. `wcs.trans` 는 장바구니 · 구매 전환용이라
신청 · 상담 전환을 집계하지 않는다. mytruck 의 `site/assets/site.js` 에 있는
`mtConversion` 함수를 그대로 가져와 인증키만 바꾸면 된다.

설치 후 네이버에서 받은 메일의 **자가설치 후 검수요청**까지 마쳐야 집계가 시작된다.
